# Privacy Review Checklist

Before pushing to a shared remote, and again before any public release, check for:

- real names, handles, agent names, customer names, or project names;
- Discord guild, channel, thread, user, or message ids;
- hostnames, container ids, IP addresses, or local filesystem paths;
- secrets, tokens, webhook URLs, API keys, auth state, cookies, or credentials;
- operational transcripts copied from a private deployment;
- examples that imply access to private infrastructure;
- package metadata that points to private-only systems.

Use generic placeholders in examples and tests.
